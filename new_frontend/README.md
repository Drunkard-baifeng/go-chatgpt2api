# ChatGPT2API · CPA 风格控制台

Status: current

独立的 Vue 3 前端入口，采用 CPA-Manager-Plus 风格的淡蓝背景、半透明侧栏、
白色卡片和蓝色操作按钮。包含浅色、深色和跟随系统主题。

本目录包含完整源码、接口适配器、状态仓库、业务组件和页面 runtime，
图标与图表资源位于自己的 `src/` 和 `public/`。安装、构建和运行不读取
Python 目录；前后端通过 HTTP 连接。实际能力子集、迁移阻塞和验证状态见 [Go 后端说明](../go_backend/README.md)，也可通过显式 HTTP 目标选择已有兼容服务。
可以单独复制本目录，使用自己的 `package.json` 和锁文件安装依赖。

## 本地运行

先按 [运行环境](../README.md#运行环境) 安装 Node.js。版本文件位于本目录 `.node-version`，安装时通过 `engines.node` 和 `.npmrc` 拒绝旧补丁。

在仓库根目录安装本入口的依赖：

```powershell
npm --prefix new_frontend ci --registry=https://registry.npmjs.org
npm --prefix new_frontend run dev
```

也可以进入本目录后直接执行 `npm ci --registry=https://registry.npmjs.org` 和 `npm run dev`。
开发地址默认为 `http://127.0.0.1:5176`，以 Vite 实际输出为准。
使用现有管理密钥或用户密钥登录，源码不包含密钥。

开发代理默认连接 `http://localhost:8099`。连接默认监听 8100 的 Go 后端时：

```powershell
$env:VITE_DEV_API_TARGET = 'http://127.0.0.1:8100'
npm --prefix new_frontend run dev
```

代理覆盖 `/auth`、`/api`、`/version`、`/v1`、`/images`、`/image-thumbnails`
和可编辑文件下载的 `/files`。前端使用原接口和权限判断。

## 构建与预览

```powershell
npm --prefix new_frontend run build
npm --prefix new_frontend run preview
```

构建输出为 `new_frontend/dist`；本地预览使用 4176 端口并保留同一后端代理。
构建不会覆盖 `old_frontend/dist` 或切换后端静态页面。生产部署需要由现有反向代理
单独托管该目录，并将上述接口路径转发到后端，参考 [Nginx 示例](../deploy/nginx-server.conf.example)。

工具栏保留接口信息、服务链接、版本检查/更新与退出登录。
账号表格中 AT、RT、账号状态、来源、套餐和分组分别展示；账号 ID 放在账号名称下方，
调用次数合并为「成功 / 失败」一列，用绿色和红色区分。
宽度不足时在表格容器内横向滚动，凭据与状态详情可通过悬浮或键盘聚焦查看。

不会自动迁移原界面的浏览器历史。后端账号、日志和配置来自开发代理所连接的服务。

## 批量导入 AT 和 RT

在账号管理选择「导入 / 添加」→「导入 AT + RT」，粘贴多行文本或读取 TXT 文件：

```text
access_token_1----refresh_token_1
access_token_2----refresh_token_2
```

每行一个账号，使用四个连字符分隔 AT 和 RT，空行会跳过，两侧空白会去除。
两项均必填；任一行格式错误时显示行号，整批不保存。格式正确后沿用现有的分组、
保存及账号额度同步流程；重复 AT 更新对应账号凭据，同一批次以最后一行的 RT 为准。

## 代理管理

代理组直接展示全部节点，地址、出口 IP、地区、HTTP、耗时和图片并发分别展示；每组可批量测出口，每个启用节点也可单独测试。测试结果和组摘要就地更新，部分失败显示“部分可用”，不会拿第一个节点的状态代表整组。地区为探测返回的两位地区代码，未返回时显示“—”。

节点表按字段显式分配列宽，地址列不再吸收全部空余空间；认证用地址旁的钥匙图标表示，悬停显示说明。字号与账号管理对齐：组名和节点名称 14px，表头、正文、状态和按钮 12px，辅助说明 11px；大屏沿用同一字号，窄屏继续按字段排列。

新建组填写名称后可逐行添加，或点击“批量粘贴”，每行填写 `代理地址 图片并发`；省略并发默认 30，0 表示不限。添加只写入草稿，点击创建或保存后生效。组 ID 默认自动生成，也可展开自定义。编辑采用节点表格，可调整名称、备注、地址、图片并发和启用状态；手机改为纵向字段布局。

已保存代理地址中的认证不回显，地址不变时保留认证；替换认证需要填写完整 URL。修改地址后旧草稿测试结果隐藏，保存组后旧组测试统计清除。最近探测来自当前后端进程，重启后需要重新测试；连接可用不代表生成请求必定成功。验证边界见 [后端说明](../go_backend/README.md#账号与控制面)。

## 设计与维护

- 用户密钥的管理员页面为 `/user-keys`，入口位于外层主导航，不再作为系统设置分组。路由由 `src/router/routes.ts` 注册，`src/layouts/AppShell.vue` 维护导航、标题与缓存，`src/views/UserKeys.vue` 和同目录 `user-keys/` 维护列表及弹窗生命周期。
- 用户密钥列表按名称、状态、创建时间、最近使用和操作分列，时间按北京时间显示到秒；手机端改为带字段名的紧凑布局。完整密钥仍仅在创建后短暂展示一次，刷新失败保留已有列表；分组、并发、用量及过期时间等后端未提供的字段不展示。
- `src/styles/theme.css`：两套主题及 Nanocat 语义变量。
- `src/styles/workspace.css`：导航、页面布局、响应式规则。
- `src/views`：新入口的独立页面组合。
- `src/components/ui`：独立的面板、标题、筛选栏、空态、表单区块和弹窗展示组件；业务组件直接导入这些本地实现。
- 新入口自行定义展示组件的 `--app-*` 变量，并与 CPA 主题关联；Nanocat 继续提供按钮、选择器、浮层焦点管理等基础行为。长弹窗限制在视口内滚动，账号组窗口支持 Escape 关闭并保留保存中的关闭保护。
- `@/` 和 `~/` 都指向本目录的 `src/`，不配置跨前端别名、软链接或共享源码目录。
- 表单分区直接导入本地 `FormSection.vue`；其余基础控件使用已声明的 Nanocat npm 包。
- Tailwind 只扫描本目录。业务组件保留编辑、虚拟列表和浮层所需的局部结构样式，未迁入原前端全局样式、页面外壳和旧路由。
- 路由名、权限元数据和业务事件处理器保持兼容；`src/api`、`src/stores`、`src/composables` 和各页面 runtime 在本入口内维护。
- 构建时的前端版本读取自己的 `package.json`；发布时与后端版本一并维护。
- 样式参考来源、适配范围与许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。
- 内容随可用视口铺满，桌面边距为 20px；顶栏 50px，侧栏展开 210px、折叠 54px。4K 下不再限制为 1920px 内容宽度。
- 分组导航、背景 SVG、指标卡和设置分组参考上游对应组件源码；业务控件继续使用 Nanocat。
- 概览把运行信息和资源占用分为两块；监控诊断卡在大屏使用三列、中屏两列、窄屏一列。配置页保留上游配置编辑器专用的 48px 输入框，不与普通列表的紧凑输入框混用。
- 新入口新增 Lucide 图标后运行 `npm --prefix new_frontend run icons:generate`；构建会通过 `icons:check` 校验本地图标集合。

构建、隔离浏览器检查及已有真实上游实测范围由 [Go 后端说明](../go_backend/README.md#构建与验证) 维护；隔离界面检查不能代替真实外部服务或用户验收。
